# NeuroFlow Studio

Красивый веб-интерфейс + консольный AI-ассистент с отображением логики размышления.

## Что умеет

- Стильный chat UI (glassmorphism + градиенты).
- Обработка сообщений через AI engine.
- Показывает интент, уверенность и шаги рассуждения.
- Отдельный режим работы в консоли для общения без браузера.

## Запуск

```bash
npm start
```

Открой: `http://localhost:3000`

## Консольный режим

```bash
npm run cli
```

Команды в консоли:

- `/help` — помощь
- `/exit` — выход
